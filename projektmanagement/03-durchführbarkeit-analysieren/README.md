# Durchführbarkeit analysieren

## Allgemeines

Die **Durchführbarkeit eines Projektes** wird anhand verschiedener Bereich festgestellt. Falls das Projekt **nicht durchführbar** ist, muss eine **neue Idee** gesucht werden.

Fragestellung dazu: Ist es möglich die Projektziele mit den gegebenen Bedingungen zu erreichen?

Folgende Faktoren könnten in der Softwareentwicklung relevant sein:

- Technologische Durchführbarkeit: Know-How, Technologie, ...  
- Ökonomische Durchführbarkeit: Kosten-Nutzen-Analyse, reichen die Ressourcen für die geplanten Aufgaben
- Rechtliche Durchführbarkeit: entspricht die Software den Gesetzen **im Zielmarkt**, DSGVO
- Terminlich Durchführbarkeit: sind Deadlines realistisch

Berücksichtigt wird auch: Personalressource, finanziellen Ressourcen, zeitlichen Ressourcen, ...
