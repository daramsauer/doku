# Was ist ein Projekt?

Ein Projekt ist ein Ereignis, das dazu dient ein bestimmtes **Ergebnis** zu erzielen (ein **klares Ziel** ). *Erfahrungen* aus dem Projekte **transferiert** werden.

## Gründe für ein Projekt

#### Folgende Gründe sprechen für durchführung einer Arbeit als Projekt:

- Eine *individuelle* Problemlösung ist notwendig
- Aufgabe ist komplex.
- Eventuell ist eine Innovation notwendig.
- Es handelt sich um kein Alltagsgeschäft des Unternehmen(keine Routinetätigkeit)

## Eigenschaften von Projekten

- klares Ziel
- ein definierter Zeitrahmen
- komplexe, neuartige Aufgabe
- es herrscht ein soziales System(innen und außen)
- die verfügbaren Ressourcen sind begrenzt (Personal, Geld, Material, Know How, ...)
> **Hinweis:** Ein **Stakeholder** ist eine Person, die am Verhalten eines Unternehmens interessiert ist (zB Aktionär, Mitarbeiter, Kunde, Lieferant, ...)
