# Was ist ein Projekt

Ein Projekt ist ein Ereignis, das dazu dient ein bestimmtes **Ergebnis** zu erzielen (ein **klares Ziel**). *Erfahrungen* aus dem Projekt
sollen auf kommende Projekte **transferiert** werden.

## Gründe für ein Projekt

Folgende Gründe sprechen für die Durchführung einer Arbeit als Projekt:
- Eine *individuelle* Problemlösung ist notwendig (Standard kann automatisiert werden)
- Aufgabe ist komplex
- Eventuell Innovation im Betrieb notwendig
- Es handelt sich um kein Alltagsgeschäft
