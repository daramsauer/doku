# Projektarten

Projekte können anhand der folgenden Merkmale unterschieden werden:

- Komplexität (mittel, hohe)
- Branche
- Konkretisierung (Konzeptionsprojekt, Realisierungsprojekt)
- Wiederholungsgrad (einmalige Projekte, sich wiederholende Projekte)
- Auftraggeber (interne und externe Projekte)
- inhaltliche Ziele (Auftragsprojekt, Marketingprojekt, Organisationsentwicklungsprojekt)
- Größe (kleine, mittelgroße, Großprojekte)
- Dauer (kurz, mittellang, lang)
- Risiko (mittleres Risiko, hohes Risiko)
